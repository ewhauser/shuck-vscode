# Changelog

All notable changes to the Shuck Visual Studio Code extension are documented in
this file.

## 0.1.0

- Add the first-party client for `shuck server`.
- Support local, remote, untitled, and multi-root shell documents.
- Add executable validation, version checks, lifecycle commands, output
  channels, and server status UI.
- Forward editor-specific global and per-workspace configuration.
- Add reproducible VSIX packaging, CI, release automation, and extension-host
  smoke tests.
